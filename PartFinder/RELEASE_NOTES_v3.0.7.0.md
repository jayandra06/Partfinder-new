- **Master Data:** Auto-save on catalog edits (debounced); import progress and large-catalog pipeline; admin delete with cascade cleanup; empty-state and read-only hints; no redundant Save catalog when viewing catalog data.

- **Services:** Worksheet relation cleanup on catalog delete; master data source field encoding and cascade.
